<objective>
Allow the user to rename the current chat conversation directly from the chat screen's top bar on iOS, Android, and Desktop. Today the rename UI only exists in the conversation list (long-press / context menu); when the user is inside a chat, the title is read-only.

This plan reuses the existing Rust core path (`AppAction::RenameConversation` -> `persistence::queries::rename_conversation` -> `refresh_conversations`) — no UniFFI bindings change. The work is: (1) add a small defensive guard in the Rust core so empty/whitespace titles are ignored (preventing a broken empty list entry if any UI ever sends one), and (2) wire a tap-on-title editing affordance in each chat top bar that dispatches the existing action.

Purpose: Quality-of-life. Users currently must back out to the conversation list to rename. Discoverability of the existing rename feature is also low.

Output: Tap conversation title in chat -> dialog/inline edit -> save -> title updates in chat header AND in sidebar/list immediately. Empty input leaves title unchanged.
</objective>
