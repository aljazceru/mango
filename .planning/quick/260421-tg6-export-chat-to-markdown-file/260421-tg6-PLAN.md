<objective>
Add the ability to export a chat conversation to a local Markdown file.

Purpose: Users want to take their conversations out of the app (paste into notes, share with collaborators, archive). Per project privacy constraints, export is strictly local: we render markdown in the Rust core, hand bytes to the native layer, and the native layer writes to a user-chosen path via the OS file dialog. No cloud, no telemetry.

Output:
- A new Rust-core FFI method `export_conversation_markdown(conversation_id) -> Result<String, FfiError>` (query-style, mirroring `read_encrypted_image` / `list_directory_fingerprints`) that loads messages from SQLite and returns a formatted markdown string.
- A pure, unit-tested markdown formatter helper in the core (no DB, no FFI) so logic is covered by tests and reusable by the other platforms.
- Desktop (iced) UI wire-up: an "Export as Markdown…" entry in the existing conversation (···) menu that opens `rfd::FileDialog` and writes the returned string.

Scope decision (explicit): per the task's guidance to scope one platform first when doing all three would blow the 1–3 task budget, **this plan ships Rust core + Desktop only**. iOS (`ShareLink` with the markdown string or a temp file) and Android (`ACTION_SEND` / `CREATE_DOCUMENT`) reuse the exact same FFI method and are a trivial follow-up quick task per platform.
</objective>

```rust
pub fn read_encrypted_image(&self, message_id: String) -> Result<Vec<u8>, FfiError> {
    let (reply_tx, reply_rx) = flume::bounded(1);
    self.core_tx.send(CoreMsg::ReadEncryptedImage { message_id, reply: reply_tx })
        .map_err(|e| FfiError::Internal { reason: format!("actor channel error: {e}") })?;
    reply_rx.recv()
        .map_err(|e| FfiError::Internal { reason: format!("actor reply error: {e}") })?
        .map_err(|reason| FfiError::Internal { reason })
}
```
