<objective>
Unify "Documents" and "Folders" into a single RAG surface on all three platforms. Today the Home toolbar exposes two separate buttons — "Documents" / "RAG" and "Folders" / "Sources" — routing to two distinct screens (Screen::Documents and Screen::DirectorySources). The user's model is simpler: folders are one kind of RAG source, alongside documents, and later other types (URLs, notes, etc.).

This plan consolidates the UI only. It keeps the Rust core (Screen variants, actions, DocumentSummary, DirectorySourceSummary, bookmark rehydration) intact. The existing DirectorySources screen and its picker component remain in code as a detail/legacy route, but the Home entry point is removed and the functionality is folded into the existing Document Library screen, which is renamed to "RAG" / "Sources".

Purpose: Match the user's mental model — one RAG feature, multiple source types — and leave room for future source types without more top-level nav.
Output: A single "RAG" entry on Home per platform. One screen listing Documents + Directory Sources. One Add action opening a source-type picker (Document | Folder).
</objective>
