<objective>
Close VERIFICATION.md gap #1 (truth #12 / HI-01). Make iOS periodic sync work across cold launch by adding a targeted FFI accessor for `directory_sources.bookmark_data` and rehydrating `DirectorySyncScheduler.bookmarkCache` at `AppManager.init` time before the first `ScenePhase.active` fires.

Purpose: the roadmap goal phrase "automatic incremental re-sync across launches" is currently violated on iOS — `DirectorySyncScheduler.bookmarkCache` is a process-local static and is empty after cold launch, so every pre-existing source is silently skipped. 32-05-SUMMARY documents this as a known v1 limitation; this plan converts it into a fix.

Output: Rust FFI additions + regenerated UniFFI bindings + iOS rehydration call site. `bookmark_data` remains excluded from `DirectorySourceSummary` per T-32-I2 — this new accessor is a per-source targeted read, not a broadening of the summary type.
</objective>
