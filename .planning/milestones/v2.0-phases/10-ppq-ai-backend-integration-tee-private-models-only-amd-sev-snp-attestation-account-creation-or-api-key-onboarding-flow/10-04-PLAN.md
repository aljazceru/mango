# Plan 10-04 — Attestation Routing and Streaming Integration

## Goal

Integrate PPQ attestation verification into existing attestation infrastructure and add PPQ streaming support to agent loop.

## Tasks

### Task 1: Add PPQ attestation routing to attestation endpoint

Update `rust/src/attestation/endpoint.rs`:
- Add ProviderKind::Ppq case to attestation endpoint dispatch
- Check if backend.transport_kind() is PpqPrivateE2ee
- Route to PPQ-specific attestation verification path

### Task 2: Add PPQ attestation routing to attestation task

Update `rust/src/attestation/task.rs`:
- Add ProviderKind::Ppq case to attestation task dispatch
- Check if backend.transport_kind() is PpqPrivateE2ee
- Call `crate::llm::ppq_private::verify_backend_attestation()`
- Pass SNP policy for SEV-SNP verification

### Task 3: Add PPQ streaming support to streaming module

Update `rust/src/llm/streaming.rs`:
- Add PpqPrivateE2ee case to stream type detection
- Route to `crate::llm::ppq_private::run_streaming_chat_completion`
- Add PpqPrivateE2ee case to API message streaming
- Route to `crate::llm::ppq_private::run_streaming_chat_completion_from_api_messages`
- Handle PPQ-specific response format

### Task 4: Add PPQ dispatch to agent loop

Update `rust/src/agent/loop.rs`:
- Add ProviderTransportKind::PpqPrivateE2ee case to tool dispatch
- Call `crate::llm::ppq_private::create_chat_completion()` for PPQ backends
- Pass backend, model, messages, and tools parameters

### Task 5: Add PPQ model prefix filtering

Update `rust/src/lib.rs`:
- Add PPQ.AI to model prefix filtering logic
- Filter models to only include "private/" prefix for PPQ.AI
- PPQ.AI exposes 300+ models but only private models are supported

## Success Criteria

1. Attestation endpoint routes PPQ backends to PPQ verification
2. Attestation task calls PPQ verification function
3. Streaming module routes PPQ requests to PPQ streaming functions
4. Agent loop dispatches PPQ tool calls to PPQ completion function
5. PPQ model filtering only includes "private/" prefix models

## Dependencies

- Plan 10-01 (ppq_private module)
- Plan 10-02 (transport kind and TEE type)
