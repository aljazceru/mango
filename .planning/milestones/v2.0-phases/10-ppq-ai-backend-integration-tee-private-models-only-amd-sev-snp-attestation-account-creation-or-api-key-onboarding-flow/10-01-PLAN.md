# Plan 10-01 — Core PPQ Private Transport Module

## Goal
Implement PPQ.AI private transport with EHBP (Encrypted HTTP Body Protocol) using HPKE encryption, AMD SEV-SNP attestation verification, and SSE streaming support.

## Tasks

### Task 1: Create ppq_private.rs module structure
Create `rust/src/llm/ppq_private.rs` with:
- EHBP protocol constants (paths, labels, key lengths)
- `VerifiedPpqAttestation` struct for caching attestation results
- `AttestationBundle` and related structs for parsing PPQ attestation responses
- HPKE encryption/decryption functions
- Request/response nonce handling
- Error types for PPQ-specific failures

### Task 2: Implement HPKE encryption
Implement HPKE (Hybrid Public Key Encryption) for PPQ private transport:
- `setup_sender` for key encapsulation
- AES-256-GCM for request body encryption
- HKDF-SHA256 for key derivation
- Response key and nonce derivation
- Zeroization of sensitive materials

### Task 3: Implement attestation verification
Implement AMD SEV-SNP attestation verification:
- Parse attestation bundle from PPQ endpoint
- Extract and verify SEV-SNP report using `sev` crate
- Parse X.509 enclave certificate
- Validate VCEK (Verifiable Certificate for Enclave)
- Cache verified attestations with TTL

### Task 4: Implement chat completion API
Implement non-streaming chat completion:
- `create_chat_completion` function
- Encrypt request body with HPKE
- Send to PPQ private endpoint
- Decrypt response with derived keys
- Handle PPQ-specific response format

### Task 5: Implement streaming chat completion
Implement SSE streaming for PPQ:
- `run_streaming_chat_completion` function
- `run_streaming_chat_completion_from_api_messages` function
- Handle PPQ private SSE format
- Decrypt streaming chunks
- Handle stream cancellation
- Parse encrypted response chunks

## Success Criteria
1. `rust/src/llm/ppq_private.rs` module exists with all functions
2. HPKE encryption/decryption works with test vectors
3. AMD SEV-SNP attestation verification parses and validates reports
4. Non-streaming chat completion encrypts request and decrypts response
5. Streaming chat completion handles encrypted SSE chunks
6. Attestation caching works with TTL
7. All sensitive materials are zeroized

## Dependencies
- `aes-gcm` crate for AES-256-GCM
- `hpke` crate for HPKE operations
- `sev` crate for SEV-SNP parsing
- `x509-parser` for certificate parsing
- `reqwest` for HTTP client
- Existing attestation infrastructure
