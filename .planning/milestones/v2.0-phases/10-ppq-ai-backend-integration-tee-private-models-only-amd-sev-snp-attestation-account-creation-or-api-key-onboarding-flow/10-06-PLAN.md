# Plan 10-06 — Test Coverage for PPQ

## Goal

Create comprehensive test coverage for PPQ transport, provider presets, attestation verification, and streaming cancellation.

## Tasks

### Task 1: Create live PPQ attestation tests

Create `rust/src/tests/live_ppq_private.rs`:
- `live_ppq_private_attestation_verifies`: Test PPQ attestation verification with test API key
- `live_ppq_private_rejects_invalid_api_key`: Test that invalid API keys are rejected
- Use actual PPQ.AI endpoint for live integration tests

### Task 2: Add PPQ preset tests

Update `rust/src/tests/backend_config.rs`:
- `test_known_provider_presets_includes_ppq_ai`: Verify PPQ preset exists in known_provider_presets()
- `test_ppq_ai_supports_tool_use`: Verify PPQ.AI backend supports tool use
- `test_parse_tee_type_handles_amd_sev_snp`: Verify AmdSevSnp parsing

### Task 3: Add PPQ transport tests

Update `rust/src/tests/transport.rs`:
- `test_ppq_private_base_url_selects_private_transport`: Verify PPQ private URL selects PpqPrivateE2ee transport
- `test_ppq_private_transport_errors_on_openai_api_base`: Verify PPQ transport returns error for OpenAI path
- `test_ppq_private_model_list_url`: Verify model list URL returns correct endpoint

### Task 4: Add migration tests

Update `rust/src/tests/persistence.rs`:
- `test_migration_v11_seeds_ppq_ai_private_transport`: Verify V11 updates base_url to private transport
- Query ppq-ai row directly and verify tee_type and base_url

### Task 5: Add streaming cancellation test

Update `rust/src/tests/streaming.rs`:
- `test_stop_generation_cancels_ppq_stream`: Document PPQ coverage of cancellation path
- Test that StopGeneration + StreamCancelled transitions to Idle for PPQ

### Task 6: Register test module

Update `rust/src/tests/mod.rs`:
- Add `mod live_ppq_private;` to register new test module

## Success Criteria

1. Live PPQ attestation tests pass with valid API key
2. Invalid API key test fails as expected
3. PPQ preset tests verify correct configuration
4. PPQ transport tests verify transport kind selection
5. Migration tests verify V10/V11 applied correctly
6. Streaming cancellation test documents PPQ path
7. All tests pass in `cargo test -p mango_core`

## Dependencies

- Plan 10-01 (ppq_private module)
- Plan 10-02 (transport kind and TEE type)
- Plan 10-03 (migrations)
- Plan 10-04 (attestation and streaming integration)
