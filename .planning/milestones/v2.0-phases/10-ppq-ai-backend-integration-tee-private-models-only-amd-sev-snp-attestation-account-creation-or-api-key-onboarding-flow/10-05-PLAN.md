# Plan 10-05 — UI Integration Across All Platforms

## Goal

Add PPQ.AI provider links and AmdSevSnp TEE type support to Android, iOS, and Desktop onboarding and settings screens.

## Tasks

### Task 1: Android ppq.ai link

Update `android/app/src/main/java/dev/disobey/mango/ui/OnboardingScreen.kt`:
- Add ppq.ai tappable link to onboarding no-key state
- Link opens https://ppq.ai in browser
- Display text "ppq.ai" with primary color

### Task 2: Android AmdSevSnp TEE type support

Update `android/app/src/main/java/dev/disobey/mango/ui/SettingsProvidersScreen.kt`:
- Add "AmdSevSnp" to TEE type picker options
- Add teeTypeLabel() mapping for TeeType.AMD_SEV_SNP → "AMD SEV-SNP"
- Update parseTeeType() to handle "AmdSevSnp" string

### Task 3: iOS ppq.ai link

Update `ios/Mango/Mango/OnboardingView.swift`:
- Add ppq.ai Link to onboarding no-key state
- Link opens https://ppq.ai
- Display text "ppq.ai"

### Task 4: iOS AmdSevSnp TEE type support

Update `ios/Mango/Mango/OnboardingView.swift`:
- Add .amdSevSnp case to teeTypeLabel() returning "AMD SEV-SNP"

Update `ios/Mango/Mango/SettingsProvidersView.swift`:
- Add "AMD SEV-SNP" Text with tag "AmdSevSnp" to TEE type picker
- Add .amdSevSnp case to teeTypeLabel() returning "AMD SEV-SNP"
- Add "AmdSevSnp" case to teeType(from:) returning .amdSevSnp

### Task 5: Desktop ppq.ai link

Update `desktop/iced/src/views/onboarding.rs`:
- Add ppq.ai button to onboarding no-key state
- Button opens https://ppq.ai
- Display text "ppq.ai" with accent color

### Task 6: UniFFI bindings

Regenerate UniFFI bindings to include new TEE type:
- Run `just bindings-swift` for iOS
- Run `just bindings-kotlin` for Android
- Verify AmdSevSnp appears in bindings

## Success Criteria

1. Android onboarding shows ppq.ai link
2. Android settings have AmdSevSnp in TEE type picker
3. iOS onboarding shows ppq.ai link
4. iOS settings have AmdSevSnp in TEE type picker
5. Desktop onboarding shows ppq.ai link
6. UniFFI bindings include AmdSevSnp variant
