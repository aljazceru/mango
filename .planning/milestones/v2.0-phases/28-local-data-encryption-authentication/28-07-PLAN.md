  <action>
    **iOS (per D-10):**
    - In ContentView, use `@Environment(\.scenePhase) var scenePhase`
    - `.onChange(of: scenePhase)`: when transitioning to `.background`, record `Date()` in `@State var backgroundedAt: Date?`
    - When transitioning to `.active`: if `backgroundedAt` is set and `Date().timeIntervalSince(backgroundedAt!) > Double(appState.lockTimeoutSeconds)` and `lockTimeoutSeconds != -1` (Never), dispatch `AppAction.lockApp`
    - On cold launch: always start locked (handled by Rust initial screen)

    **Android (per D-10):**
    - In MainActivity, override `onPause()` to record `System.currentTimeMillis()` in a field `var backgroundedAt: Long = 0`
    - Override `onResume()`: if `backgroundedAt > 0` and `System.currentTimeMillis() - backgroundedAt > appState.lockTimeoutSeconds * 1000` and `lockTimeoutSeconds != -1`, dispatch `AppAction.LockApp`

    **Desktop (per D-10):**
    - iced does not have a standard background/foreground lifecycle. Use window focus events if available in the iced version used, or skip background timeout for desktop (PIN lock on app restart only). Document this as a desktop limitation.
    - Alternatively, use a simple timer subscription that checks elapsed time since last user interaction.

    Use -1 as the sentinel value for "Never" (no auto-lock). Show a warning in settings when selected.
  </action>
