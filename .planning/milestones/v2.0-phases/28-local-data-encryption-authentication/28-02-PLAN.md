    pub trait BiometricProvider: Send + Sync + 'static {
        /// Returns: "available", "not_enrolled", "not_available", "not_supported"
        fn biometric_status(&self) -> String;
        /// Trigger platform biometric prompt. Blocks until user responds.
        /// Returns true on success, false on failure/cancel.
        fn authenticate(&self, reason: String) -> bool;
    }

    pub struct NullBiometricProvider;
    impl BiometricProvider for NullBiometricProvider {
        fn biometric_status(&self) -> String { "not_supported".to_string() }
        fn authenticate(&self, _reason: String) -> bool { false }

    **FfiApp::new changes (per D-12):**
    - Add `biometric_provider: Box<dyn BiometricProvider>` parameter to `FfiApp::new()`
    - Store biometric_provider in ActorState
    - Change `db` field in ActorState from `Database` to `Option<Database>` -- set to `None` initially
    - Remove the immediate `Database::open()` call from the actor thread constructor
    - Instead, open the bootstrap DB: `let bootstrap = BootstrapDb::open(&format!("{}/mango_auth.db", data_dir))`
    - Store `bootstrap: BootstrapDb` in ActorState
    - Check `bootstrap.has_auth_params()`:

      - If false: set initial screen to `Screen::PinSetup` (first time)
    - Query `biometric_provider.biometric_status()` and set `AppState.biometric_available = (status == "available")`
    - Do NOT load backends, conversations, memories, etc. until after unlock (all those operations need `db`)

    **Actor handler for UnlockWithDek:**
    1. Take the `dek_hex` string
    2. Determine if existing unencrypted DB needs migration: if file exists and `Database::is_encrypted(&db_path)` is false, call `Database::migrate_to_encrypted(&db_path, &dek_hex)`
    3. Open encrypted DB: `Database::open_encrypted(&db_path, &dek_hex)`
    4. Store in `self.db = Some(db)`
    5. Load backends, conversations, memories, documents from the now-open DB (move the existing post-open code from FfiApp::new into a `fn load_post_unlock(&mut self)` helper)
    6. Set `screen` to `Screen::Home` (or restore saved pre-lock screen if LockApp was used)
    7. Emit full AppState update

    **Actor handler for UnlockWithPin:**
    1. Read auth_params from bootstrap DB
    2. Check duress PIN first (per D-19): if `auth_params.duress_hash.is_some()`, call `verify_pin_hash(pin.as_bytes(), &duress_hash)` -- if match, execute DuressWipe logic (per D-15: delete mango.db, all data_dir files, all keychain entries, bootstrap DB delete_all, set screen to Onboarding)
    3. Derive KEK: `derive_kek(pin.as_bytes(), &salt, kdf_memory_kib, kdf_iterations, kdf_parallelism)`
    4. Unwrap DEK: `unwrap_dek(&kek, &wrapped_dek)` -- if fails, show toast "Incorrect PIN"
    5. Convert DEK to hex, store in keychain (per D-06, so biometric path works next time): `keychain.store("mango", "dek", hex::encode(&dek))`
    6. Proceed as UnlockWithDek

    **Actor handler for SetupPin (per D-14, D-18):**
    1. Generate DEK: `generate_dek()`
    2. Generate salt: `generate_salt()`
    3. Derive KEK from PIN: `derive_kek(pin.as_bytes(), &salt, DEFAULT_MEMORY_KIB, DEFAULT_ITERATIONS, DEFAULT_PARALLELISM)`
    4. Wrap DEK: `wrap_dek(&kek, &dek)`
    5. If duress_pin provided: generate duress_salt, hash duress PIN: `hash_pin(duress_pin.as_bytes(), &duress_salt)`
    6. Write to bootstrap DB: `write_auth_params(&AuthParams { salt, wrapped_dek, duress_hash, duress_salt, kdf_* })`
    7. If enable_biometric: store DEK in keychain: `keychain.store("mango", "dek", hex::encode(&dek))`
    8. Open encrypted DB (create new): `Database::open_encrypted(&db_path, &hex_dek)`
    9. Set `self.db = Some(db)`, set screen to `Screen::Home`
    10. Emit full AppState update

    **Actor handler for LockApp (per D-10):**
    1. Save current screen to `self.pre_lock_screen = Some(current_screen.clone())`
    2. Drop database: `self.db = None` (close connection, release DEK access)
    3. Set screen to `Screen::Locked`
    4. Emit minimal AppState (no chat/memory/backend data)

    **Actor handler for AttemptBiometricUnlock (per D-06, D-11):**
    1. Call `self.biometric_provider.authenticate("Unlock Confidential App".to_string())`
    2. If returns true: load DEK from keychain `keychain.load("mango", "dek")`
    3. If DEK found: dispatch UnlockWithDek logic
    4. If returns false or DEK not found: show toast "Biometric authentication failed"

    **Actor handler for SetLockTimeout (per D-13):**
    1. Persist: `set_setting(db.conn(), "lock_timeout_seconds", &seconds.to_string())`
    2. Update `AppState.lock_timeout_seconds`

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PIN input -> actor thread | Untrusted PIN crosses from UI to Rust actor |
| Keychain -> DEK | Platform keychain returns DEK; trust boundary = biometric gate |
| BiometricProvider callback | Platform code returns auth result; Rust trusts it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-09 | Spoofing | BiometricProvider.authenticate | accept | Trust platform biometric implementation (LAContext/BiometricPrompt); Rust cannot independently verify biometric match |
| T-28-10 | Information Disclosure | ActorState.db = None | mitigate | No DB-dependent data emitted in AppState while locked; guard on every handler |
| T-28-11 | Tampering | UnlockWithPin | mitigate | Duress PIN checked before DEK unwrap via constant-time verify_pin_hash; wrong PIN causes unwrap_dek failure (GCM tag mismatch) |
| T-28-12 | Denial of Service | LockApp | accept | User can lock themselves out if they forget PIN and biometrics fail; recovery = reinstall (acceptable for security app) |
| T-28-13 | Information Disclosure | pre_lock_screen | mitigate | pre_lock_screen stores Screen enum variant only (no sensitive payload); cleared on DuressWipe |
| T-28-14 | Elevation of Privilege | DB-dependent handlers | mitigate | Every handler checks Option<Database> is Some before proceeding; None = reject action |
</threat_model>
