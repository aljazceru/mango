# Phase 34.1 Plan 05: iOS SwiftUI sub-lines for Redpill freshness + orchestrated breakdown — Summary

**One-liner:** Mirrored the Android sub-line rendering on iOS — `Settings → Providers` now shows the LOCKED-copy "Verified for this enclave instance" freshness sub-line (RED-09) and the "gateway ✓ • model ✓ • compose ✓" orchestrated-component breakdown sub-line (RED-11) under the existing attestation pill, plus a compile-fix sweep across five Swift files for the new `AttestationStatus.verified(shape:freshness:orchestratedComponents:)` struct variant.

## What Was Done

1. **Task 1 — Compile-fix sweep (commit `b5fa45a`)** — Updated every bare `case .verified:` pattern-match site in non-providers iOS Swift files to bind associated values explicitly:
   - `AttestationBadgeView.swift` lines 39, 52, 103 → `case .verified(_, _, _):`
   - `AppColors.swift` lines 85-86, 99-100, 113-114 → `case (.verified(_, _, _), .dark):` and `case (.verified(_, _, _), _):` tuple patterns
   - `ModelPickerView.swift` lines 50, 60 → `case .verified(_, _, _):`
   - `OnboardingView.swift` line 294 → `case .verified(_, _, _):`
   - `ChatView.swift` lines 144 and 292 inspected — no pattern-match sites (those lines reference `activeAttestationStatus` as a value, not in a switch). No edit.
   No behavior change; visible label / color / text returned in each site is identical.

2. **Task 2 — Sub-line rendering in SettingsProvidersView.swift (commit `4a88567`)** — Inside `enabledRow(_:)`'s outer `if let backend` block, added a 25-line sub-line block immediately after the HStack containing the health pill + attestation pill, and before the models-prefix Text. The block:
   - Looks up `att = appState.attestationStatuses.first(where: { $0.backendId == backend.id })`.
   - Pattern-matches `if case let .verified(_, freshness, components) = att.status`.
   - When `freshness == "PerEnclave"`: emits `Text("Verified for this enclave instance").font(.caption2).foregroundColor(.secondary)`.
   - When `components` is non-nil and non-empty: builds the breakdown line via `comps.map { "\(labelMap[$0.label] ?? $0.label) ✓" }.joined(separator: " • ")` with `labelMap = ["gateway": "gateway", "model": "model", "compose_manager": "compose"]`, then emits a second `Text` with the same caption2 + secondary style.
   - Same commit also updated `attestationStyle(_:_:)` private fn at line 243: `case .verified:` → `case .verified(_, _, _):` (compile-fix).
