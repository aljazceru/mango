Encoding decisions:
- `shape`: store canonical strings ("Flat" | "Orchestrated" | "Chutes") directly.
- `freshness`: ("PerRequest" | "PerEnclave") directly.
- `orchestrated_components`: `serde_json::to_string(&Option<Vec<(String, String)>>)` → e.g. `[["gateway","0xAA"],["model","0xBB"],["compose_manager","0xCC"]]`. List-of-pairs (not object) so duplicate-label edge cases survive.

Cache CRUD shape (per PATTERNS.md):
- `put` (cache.rs:150-169): INSERT OR REPLACE — extend column list and params! with three new bind sites.
- `get` (cache.rs:49-91), `get_latest_for_backend` (cache.rs:99-144): SELECT extends with three columns; build `AttestationRecord` with the new fields populated; build the resulting `AttestationStatus::Verified` from those columns directly (do NOT route through `deserialize_status` for the verified case — that fallback exists for non-row paths and produces None values).
- The row-mapper for the verified case constructs the UniFFI struct variant `AttestationStatus::Verified { shape, freshness, orchestrated_components }` where orchestrated_components is converted from the persisted tuple Vec into `Vec<OrchestratedComponent>` via the same conversion as 34.1-02 (`v.iter().map(|(label, value)| OrchestratedComponent { label, value })`).
- Defensive: `serde_json::from_str` failures hydrate to `None` (do NOT panic on cache poisoning).
