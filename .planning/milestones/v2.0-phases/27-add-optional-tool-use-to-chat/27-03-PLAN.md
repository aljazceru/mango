    **Step 4: Desktop -- chat.rs and main.rs**

    In `desktop/iced/src/main.rs`:
    - Add `Message::ToggleConvToolsEnabled` variant to the Message enum
    - Add handler:
    ```rust
    Message::ToggleConvToolsEnabled => {
        if let Some(conv_id) = app_state.current_conversation_id.clone() {
            let current = app_state.conversations.iter()
                .find(|c| c.id == conv_id)
                .map(|c| c.tools_enabled)
                .unwrap_or(false);
            dispatch_action(AppAction::SetConversationToolsEnabled {
                conversation_id: conv_id,
                enabled: !current,
            });
        }
    }
    ```
