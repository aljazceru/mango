5. Implement `dispatch_web_search(args_str: &str, runtime: &tokio::runtime::Runtime, brave_api_key: &str) -> String`:
   - If `brave_api_key` is empty, return `"Error: Brave Search API key not configured. Set brave_api_key in settings."`.
   - Parse `args_str` as JSON. Extract `query` (required string) and `count` (optional u64, default 5, max 10).
   - Use `runtime.block_on()` to call `reqwest::Client::new().get("https://api.search.brave.com/res/v1/web/search").query(&[("q", query), ("count", count_str)]).header("X-Subscription-Token", brave_api_key).header("Accept", "application/json").timeout(Duration::from_secs(10)).send().await?.json::<serde_json::Value>().await`.
   - On success, call `format_brave_results(&json)`.
   - On error, return `format!("Error: web search failed: {}", e)`.

6. Implement `format_brave_results(json: &serde_json::Value) -> String`:
   - Extract `json["web"]["results"]` as array.
   - If empty, return `"No results found"`.
   - Map each result to `{"title": ..., "url": ..., "description": ...}`.
   - Return `serde_json::to_string_pretty(&items)`.

7. Implement `dispatch_fetch_url(args_str: &str, runtime: &tokio::runtime::Runtime) -> String`:
   - Parse args, extract `url` (required string).
   - Use `runtime.block_on()` with `reqwest::Client::builder().timeout(Duration::from_secs(15)).build().unwrap().get(&url).send().await?.text().await`.
   - Parse HTML with `Html::parse_document(&html)`.
   - Select body with `Selector::parse("body").unwrap()`.
   - Extract text from body element using `.text().collect::<Vec<_>>().join(" ")`. Fallback to root element if no body.
   - Truncate to 8000 chars with `"... [truncated at 8000 chars]"` suffix if longer.
   - On error, return `format!("Error: failed to fetch '{}': {}", url, e)`.

8. Implement `resolve_sandbox_path(data_dir: &str, relative_path: &str) -> Result<std::path::PathBuf, String>`:
   - If `data_dir` is empty, return `Err("Error: file tool unavailable in test/in-memory mode")`.
   - If `relative_path` contains `".."`, return `Err(format!("Error: path '{}' contains '..' which is not allowed", relative_path))`.
   - Build `sandbox = Path::new(data_dir).join("agent_files")`.
   - `std::fs::create_dir_all(&sandbox)`.
   - Build `candidate = sandbox.join(relative_path)`.
   - If `!candidate.starts_with(&sandbox)`, return `Err("Error: path escapes sandbox")`.
   - Return `Ok(candidate)`.

9. Implement `dispatch_file(args_str: &str, data_dir: &str) -> String`:
   - Parse args. Extract `operation` (required string, one of "read"/"write"/"append"), `path` (required string), `content` (optional string).
   - Call `resolve_sandbox_path(data_dir, path)`. On Err, return the error string.
   - Match on operation:
     - `"read"`: `std::fs::read_to_string(&resolved)`. On error return `format!("Error: failed to read '{}': {}", path, e)`.
     - `"write"`: Require `content` parameter. Create parent dirs with `std::fs::create_dir_all(resolved.parent().unwrap())`. `std::fs::write(&resolved, content)`. On success return `format!("Wrote {} bytes to '{}'", content.len(), path)`.
     - `"append"`: Require `content` parameter. Create parent dirs. Use `OpenOptions::new().append(true).create(true).open(&resolved)` then `write_all(content.as_bytes())`. On success return `format!("Appended {} bytes to '{}'", content.len(), path)`.
     - Other: return `format!("Error: unknown file operation '{}'. Use read, write, or append.", operation)`.

10. Implement `dispatch_calculate(args_str: &str) -> String`:
    - Parse args. Extract `expression` (required string).
    - If `expression.len() > 200`, return `"Error: expression too long (max 200 chars)"`.
    - Call `evalexpr::evaluate(&expression)`. On `Ok(value)` return `value.to_string()`. On `Err(e)` return `format!("Error: math evaluation failed: {}", e)`.
