### `rust/src/attestation/cache.rs` — SQL extensions for new columns

**Analog:** same file's existing `get` (lines 49-91), `get_latest_for_backend` (lines 99-144), and `put` (lines 150-169). Pattern: `prepare_cached` → `query_row` with explicit column reads → build `AttestationRecord`.

**Read excerpt — `get_latest_for_backend`** (lines 108-135):
```rust
let mut stmt = self.conn.prepare_cached(
    "SELECT tee_type, status, report_blob, verified_at, expires_at
     FROM attestation_cache
     WHERE backend_id = ?1 AND expires_at > ?2
     ORDER BY verified_at DESC
     LIMIT 1",
)?;

let result = stmt.query_row(rusqlite::params![backend_id, now as i64], |row| {
    let tee_type: String = row.get(0)?;
    let status_str: String = row.get(1)?;
    let report_blob: Vec<u8> = row.get(2)?;
    let verified_at: i64 = row.get(3)?;
    let expires_at: i64 = row.get(4)?;
    Ok(AttestationRecord {
        backend_id: backend_id.to_string(),
        tee_type,
        status: deserialize_status(&status_str),
        report_blob,
        verified_at: verified_at as u64,
        expires_at: expires_at as u64,
    })
});
```

**Write excerpt — `put`** (lines 150-169):
```rust
self.conn.execute(
    "INSERT OR REPLACE INTO attestation_cache
     (backend_id, tee_type, status, report_blob, verified_at, expires_at)
     VALUES (?1, ?2, ?3, ?4, ?5, ?6)",
    rusqlite::params![
        record.backend_id,
        record.tee_type,
        serialize_status(&record.status),
        record.report_blob,
        record.verified_at as i64,
        record.expires_at as i64,
    ],
)?;
```

**Status (de)serialization to rework** (lines 206-232):
```rust
fn serialize_status(s: &AttestationStatus) -> String {
    match s {
        AttestationStatus::Verified => "verified".to_string(),       // ← becomes Verified { .. } => "verified"
        AttestationStatus::Unverified => "unverified".to_string(),
        AttestationStatus::Failed { reason } => format!("failed:{}", reason),
        AttestationStatus::Expired => "expired".to_string(),
    }
}

#[allow(dead_code)]
fn deserialize_status(s: &str) -> AttestationStatus {
    match s {
        "verified" | "provider_verified" => AttestationStatus::Verified,   // ← caller must rebuild struct variant from row's other cols
        // ...
    }
}
```

**Pattern to apply:**
- `serialize_status`: match `AttestationStatus::Verified { .. }` and keep emitting `"verified"` (token unchanged → backward-compatible cache rows).
- For reads: drop `deserialize_status` for the verified case (or change its signature), and rebuild `AttestationStatus::Verified { shape, freshness, orchestrated_components }` directly inside the `query_row` row-mapper, reading the three new TEXT columns. JSON-decode `orchestrated_components` via `serde_json::from_str::<Vec<(String, String)>>(...)` then map to `Vec<OrchestratedComponent>`. Defensive: `unwrap_or(None)` on JSON parse failure (do NOT panic on cache poisoning).
- `put`: extend SQL column list and `params!` with three new bind sites; serialize tuple Vec via `serde_json::to_string(&record.orchestrated_components)`. For `None` → bind `Option::<String>::None` (rusqlite treats as NULL).

## Shared Patterns

### Compile-driven sweep — `AttestationStatus::Verified` → `Verified { .. }`

**Sources:** every file matching `grep -rn 'AttestationStatus::Verified' rust/` and every Kotlin/Swift `is AttestationStatus.Verified` / `case .verified` after bindings regen.

**Apply to:** ~15 Rust sites (RESEARCH.md §"Other AttestationStatus::Verified construction sites" lists them all) + every native pattern-match site after `just bindings-kotlin && just bindings-swift`.

**Rule:** the compiler enforces it. Pattern matches that don't bind the new fields use `Verified { .. }` (Rust), `is AttestationStatus.Verified` (Kotlin smart-cast still works; bare check sufficient unless field needed), `case .verified(_, _, _)` (Swift, when associated values are not consulted).

**Construction default for non-Redpill backends:** `AttestationStatus::Verified { shape: None, freshness: None, orchestrated_components: None }`.
