# Phase 34.1 Plan 01: Close Actor-Loop Drop Site Summary

**One-liner:** Stop dropping `shape`/`freshness`/`orchestrated_components` at the actor-loop destructure by extending `AttestationRecord` with three optional fields and extracting a pure-function helper `map_event_to_record_and_status` (rust/src/attestation/mod.rs).

## What Was Done

1. **Task 1 (commit `1a401b1`)** — Extended `AttestationRecord` with `pub shape: Option<String>`, `pub freshness: Option<String>`, `pub orchestrated_components: Option<Vec<(String, String)>>`. Updated existing struct-literal call sites (`rust/src/attestation/cache.rs` row mappers, `rust/src/tests/attestation_types.rs`, `rust/src/tests/attestation_cache.rs`) to set the three new fields to `None`. The lib.rs construction site was left for Task 2.

2. **Task 2 (commit `8baf5b0`)** — Added `pub fn attestation::map_event_to_record_and_status(event, now_secs) -> (String, AttestationStatus, Option<(...)>, bool)`. The helper destructures `AttestationEvent::Verified` BY NAME (no `_` discards), threads `shape`/`freshness`/`orchestrated_components` into the constructed `AttestationRecord`, and returns `AttestationStatus::Verified` (unit variant — promotion to struct variant is owned by 34.1-02). Replaced the inline 50+ line match arm at `rust/src/lib.rs:7411-7464` with a single call to the helper. Deleted the stale "deferred to future cache columns" comment block.

3. **Task 3 (commit `9fca0bd`)** — Added table-driven test `actor_loop_threads_redpill_fields` in `rust/src/tests/redpill.rs` exercising the helper across all three Redpill shapes (Flat / PerRequest, Orchestrated / PerRequest with three components, Chutes / PerEnclave). Pure-function test — does not spin up the Tokio actor.
