    - Class holds `WeakReference<FragmentActivity>` (not strong reference)
    - `biometricStatus()`: use `BiometricManager.from(context).canAuthenticate(BiometricManager.Authenticators.BIOMETRIC_STRONG)` -- map results to "available", "not_enrolled", "not_available", "not_supported"

      3. `activity.runOnUiThread { }` to create and show BiometricPrompt

      5. In `onAuthenticationSucceeded`: set AtomicBoolean to true, latch.countDown()
      6. In `onAuthenticationFailed`/`onAuthenticationError`: latch.countDown()
      7. `latch.await()` (blocks Rust actor thread until callback fires)
      8. Return AtomicBoolean value

    Pass BiometricProviderImpl to FfiApp constructor in MainActivity.
